# ST2195 Practice Assignment 1

This repository contains my first practice assignment for ST2195.

It also demonstrates the use of RStudio, Spyder, R Markdown, Jupyter Notebook, Quarto, and GitHub for organising and documenting code.

- **R/** – RStudio project, R script and R Markdown report.
- **Python/** – Spyder project, Python script and Jupyter Notebook.
- **assignment.qmd** – Quarto document integrating R and Python.
